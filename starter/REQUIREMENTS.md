# Web名刺 要件

- 型: X のプロフィール画面風（SNS風）。スマホのみ・動き多め
- 最初に見せるもの: 実績（アプリ・LINEスタンプ）
- 名前: ぷろ / misoclub
- 肩書き: ゲームエンジニア、アプリ開発者
- アイコン: misoclub ロゴ / ヘッダー: MIO フィーチャー画像
- 配色: ダーク、アクセントは味噌色（オレンジブラウン）
- 口調: カジュアル
- セクション順: ヘッダー → プロフィール → タイムライン → リンク
- タイムライン
  - 固定: MIO / きょうの体重 / 秒速日記（画像付き）
  - キネンカ / 夜会計ナビ / 日本旅日記
  - LINEスタンプ（16種、作者ページへ）
  - YouTube（フリーBGM工房）
- リンク: X → misoclub.pro → note → YouTube（GitHub・メールは載せない）
- 画像はすべて `./assets/` に保存（misoclub.pro / LINE STORE から取得）
